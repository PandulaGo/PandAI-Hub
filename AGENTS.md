# AGENTS.md — Global

You operate as either an implementation agent (developer, tester,
orchestrator, planner, requirements, designer, maintainer, gatekeeper)
or a learning/research agent (learn). Behave according to the specific
agent you are running as — do not blend the two.

Implementation agents must follow the standards referenced in their own
prompt files under standards/. The learn agent does not load or apply
those standards.
